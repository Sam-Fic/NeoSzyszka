### 主要改进

- **跨平台发布**：新增 Linux Flatpak、Windows 便携包和 Intel / Apple Silicon macOS 磁盘映像
- **GNOME 图标一致性**：Windows 和 macOS 随包提供完整 Adwaita 与 hicolor 图标主题
- **规则与批量重命名改进**：支持编辑已有规则，采用内联进度指示并防止重复重命名操作
- **稳定性与本地化**：改进翻译，并修复文件和规则重新排序的可靠性

### Improvements

- **Cross-platform releases**: Added Linux Flatpak, Windows portable package, and macOS disk images for Intel and Apple Silicon
- **GNOME icon consistency**: Bundled complete Adwaita and hicolor icon themes on Windows and macOS
- **Rule editing and batch renaming**: Added direct editing for existing rules, inline progress feedback, and duplicate-operation protection
- **Stability and localization**: Improved translations and reliable file and rule reordering
